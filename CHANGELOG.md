# Changelog

## 2.0.0 — Isometric Pixel Edition
- Converted the playable board from flat orthographic tiles to an isometric 2.5D elevated dungeon.
- Added isometric projection and inverse diamond hit testing, including keyboard-accessible fallback.
- Added raised stone tile platforms, cliff sides, gothic structures, torches, rune circles and original pixel-art traps/hero motion.
- Reprojected hit particles, floating damage numbers, active raids and trap-placement highlights.
- Added genuine browser-rendered v2 screenshots, architectural documentation and a redesigned README.
- Preserved underlying seeded combat, AI learning and campaign saves.
- Expanded automated tests to 32 passing test cases and optional browser interaction smoke test.

## 1.1.0 — Original flat pixel renderer
- Authored 32×32 sprite cache, sprite classes, torches, gates, traps and detailed floor tiles.

## 1.0.0 — Campaign and lab
- Added waves, upgrades, classes, persistent saves, deterministic experiments and research charts.

## v2.1.0 — Clarity and telemetry

- Reorganized README into a single-column, captioned, responsive image layout; moved promotional cover under an optional expandable section.
- Added combat metrics derived from observed outcomes: defense rate, damage/hero and normalized Shannon route focus.
- Added optional colored AI-estimated route-risk overlay on isometric corridors.
- Added seed-level descriptive damage-difference interval and clarified limits of cross-policy RNG pairing.
- Improved mobile metric-card layout and switched the game-header preview to a real gameplay capture.
- Preserved deterministic combat behavior and the v2 save format.
